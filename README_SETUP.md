# Telcell Tickets — как запустить проект

Проект состоит из трёх частей, все в этой папке:
- **Flutter-приложение** (покупатель) — папка `lib/`
- **C# бэкенд** (API) — папка `backend/TelcellTickets.Api/`
- **Веб-админка** (редактор схем залов) — внутри бэкенда, `backend/TelcellTickets.Api/wwwroot/admin/`

## Что нужно установить

1. **Flutter SDK** — https://docs.flutter.dev/get-started/install (+ Chrome для веб-запуска)
2. **.NET 8 SDK** — https://dotnet.microsoft.com/download/dotnet/8.0
3. **PostgreSQL 16** — https://www.postgresql.org/download/
   При установке задать пользователя `postgres` с паролем `postgres`
   (или поменять строку подключения в `backend/TelcellTickets.Api/appsettings.json`).

## Запуск бэкенда + админки

```powershell
cd backend\TelcellTickets.Api
dotnet run
```

При первом запуске база `telcell_tickets` создастся сама (миграции) и заполнится
демо-событиями. Сервер поднимется на **http://localhost:5000**.

- Админка (редактор залов): **http://localhost:5000/admin/**
  (открывать на десктопе, ширина окна от 1280px)
- Swagger (все API): http://localhost:5000/swagger

## (Необязательно) Восстановить базу с готовыми залами

В корне лежит `db_dump.sql` — снимок базы с уже нарисованными схемами залов.
Восстановить (ДО первого запуска бэкенда, либо предварительно удалив свою базу):

```powershell
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -h localhost -U postgres -c "CREATE DATABASE telcell_tickets"
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -h localhost -U postgres -d telcell_tickets -f db_dump.sql
```
(пароль — `postgres`)

Если дамп не нужен — просто не трогай его, `dotnet run` создаст свежую базу сам.

## Запуск Flutter-приложения

```powershell
cd <корень этой папки>
flutter pub get
flutter run -d chrome
```

Приложение по умолчанию работает **на моках** (встроенные демо-данные, бэкенд не нужен).
Схема зала включена у событий **«KALEO в Ереване»** и **«Лебединое озеро»**:
открой событие → «Выбрать места».

Вход в аккаунт: любой номер телефона, код подтверждения — **0000**.
Скрытый админ-вход: номер `+37400000000`, код `9999`.

## Что проверить

**Админка** (http://localhost:5000/admin/):
1. «Шаблоны залов» → «Создать новый зал»: внизу выбери тип/цвет/цену → «＋ Добавить блок»
   → растяни прямоугольник на холсте → укажи ряды/места → «Сохранить».
2. Блок можно двигать мышью, вращать за круглую ручку сверху, менять цвет/цену.
3. Лассо по пустому месту (при выбранном блоке) — выделение отдельных кресел.
4. «Мероприятия» → «Схема зала…» → «Со схемой зала» → «Выбрать из созданных».

**Приложение**:
1. Открой «KALEO в Ереване» → «Выбрать места» → попросит войти → войди (код 0000).
2. Схема зала: вкладки этажей (Партер/Балкон), зум, тап по креслу → «Добавить».
3. Каждые ~8 секунд случайное кресло мигает голубым — эмуляция другого покупателя.
4. Выбери места → «Перейти к оплате» → оплата → билеты с QR в «Мои билеты».

## Известные ограничения (в работе)

- Flutter-приложение работает на моках; реалтайм мест в приложении — эмуляция
  (реальный WebSocket-клиент ещё не подключён, серверная часть WS готова:
  `/ws/events/{id}/seats`).
- В админке нельзя создавать новые мероприятия — только настраивать схемы у существующих.
